\# ABTC — Results Folder Guide



This folder stores \*\*outputs generated by the code\*\*, not source code itself.



> \*\*Two levels of reproducibility\*\*

>

> 1. \*\*Fast CI check\*\* (seconds–minutes): `python scripts/generate\_golden.py`  

>    Writes a compact JSON used by tests (single split). \*\*Not\*\* the paper tables.

> 2. \*\*Paper reproduction\*\* (hours): `notebooks/02\_Reproduce\_Public\_Results.ipynb`  

>    10-fold CV, isotonic calibration (3-fold inside train), and the same τ policy (metric or cost).

├─ result_metricwise/
│  └─ F2_Score.csv               # Datasets with primary_metric = F2.
                                 # Columns: Dataset, Classifier, mean, std, median (aggregated scores).
│  ├─ F1_Score.csv               # Datasets with primary_metric = F1 (same column schema as above).
│  └─ MCC_Score.csv              # Datasets with primary_metric = MCC (same schema).
│  ├─ BalanceAccuracy_Score.csv  # Datasets with primary_metric = Balanced Accuracy (same schema).
│  └─ CompleteAverageResult.csv  # Overall averages by classifier (columns include per-metric means and Rank).
├─ statistical_result/
│  ├─ Friedman_Rank.csv          # Friedman ranks per classifier per metric (lower = better).
│  └─ Wilcoxon_Score.csv         # Pairwise Wilcoxon results vs ABTCClassifier, listed per dataset.
                                 # Columns: Dataset, Classifier, p-value, δ, CI, Signif.
                                 # • δ = Cliff’s delta effect size in [-1, 1]
                                 #   (δ > 0 favors ABTCClassifier; δ < 0 favors the baseline).
                                 # • CI is the confidence interval for the effect/paired difference
                                 #   (e.g., “[0.097, 0.254]”); ‘Signif’ flags statistical significance
                                 #   under your chosen α and correction (if any).

**Effect size (Cliff’s δ):** Non-parametric effect size ∈ [-1, 1]. Magnitude guidelines (Romano et al.):

- |δ| < 0.147 → small (negligible)
- 0.147 ≤ |δ| < 0.33 → small
- 0.33 ≤ |δ| < 0.474 → medium
- |δ| ≥ 0.474 → large

Positive δ means ABTCClassifier outperforms the comparator; negative δ means the comparator is better.
